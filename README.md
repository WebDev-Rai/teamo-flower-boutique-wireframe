# Te'Amo Flower Boutique Website Wireframe

This repository contains the complete responsive client-review wireframe created by Depot Town Digital.

The website files are located in the `docs` folder. The preview is a static website, so it does not require a database, server, package installation, or build command.

## Recommended: publish with GitHub Pages

1. Create a new public GitHub repository, such as `teamo-flower-wireframe`.
2. Upload everything from this package to the repository. Keep the `docs` folder intact.
3. Open the repository's **Settings**.
4. Select **Pages** in the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/docs` folder, then click **Save**.
7. GitHub will display the public preview URL after deployment finishes.

The resulting address will normally resemble:

`https://YOUR-GITHUB-USERNAME.github.io/teamo-flower-wireframe/`

## Alternative: publish with Render

This package includes a `render.yaml` configuration file.

1. Upload this project to a GitHub repository.
2. In Render, create a new **Blueprint** and connect the repository.
3. Render will recognize the static-site configuration automatically.
4. Confirm the service and deploy it.

For a manual Render Static Site setup, use:

- Build command: `echo "No build required"`
- Publish directory: `docs`

## Local preview

Open a terminal in the `docs` folder and run:

`python -m http.server 8000`

Then visit `http://localhost:8000` in a browser.

## Important

- The pages are marked `noindex` because this is a client-review wireframe containing placeholder copy, products, prices, policies, reviews, and images.
- Replace the placeholder material only after the design is approved and Te'Amo Flower Boutique supplies its final content.
- The finished ecommerce application will require its separate production setup with the approved backend, database, payments, and business rules.
